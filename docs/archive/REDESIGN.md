# Velisqa redesign — deploy notes, image slots, test checklist

## Deploy in this order

1. **Database** — run `supabase/migrations/20261016_consolidated_checkout.sql` once in the Supabase SQL editor (safe to re-run).
   It fixes three security holes (public coupon writes, self-promotion to admin, direct order inserts) and makes the
   server charge exactly what checkout shows (COD fee + GST, free gift at ₹0, guest checkout).
2. **Edge functions** — redeploy `create-razorpay-order`, `verify-razorpay-payment`, `razorpay-webhook`,
   `nimbuspost-webhook` (`supabase functions deploy <name>`); they now use `_shared/security.ts`.
3. **Frontend** — deploy to Vercel as usual. `npm run build` = image pipeline + Vite build + prerender.
   Build needs `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` (already set) to prerender product pages.

If the frontend goes live before step 1, guest shoppers are asked to sign in at checkout (handled gracefully).

## Search & AI visibility (SEO / AEO / GEO)

Every public page is fully prerendered at build (`scripts/prerender.mjs`): real HTML content, the page's own
head tags and JSON-LD, and the catalogue it rendered with (so the browser shows it instantly). Crawlers that
don't run JavaScript — GPTBot, ClaudeBot, PerplexityBot, link previews — see the complete page.

Build outputs: `sitemap.xml`, `llms.txt` + `llms-full.txt` (site guide and catalogue for AI assistants),
`feeds/google-merchant.xml` (Google Merchant Center), `404.html` (real 404 status on Vercel).

**After each production deploy**
1. `npm run indexnow` — tells Bing / Yandex (and Bing-powered ChatGPT & Copilot search) to recrawl.
2. First time only: verify the site in Google Search Console and Bing Webmaster Tools and submit
   `https://www.velisqa.com/sitemap.xml`; in Google Merchant Center add the feed
   `https://www.velisqa.com/feeds/google-merchant.xml` (scheduled fetch, daily) for free Shopping listings.

**Keep facts consistent** — AI answers trust sites whose pages agree. Shipping fee, COD fee, delivery time
(3–5 days) and the return window (5 days) are stated in `src/data/homeFaqs.js`, `src/data/categoryFaqs.js`,
the landing pages (`seoData.js`) and the prerender's `llms.txt`; update them together with the policy pages.
