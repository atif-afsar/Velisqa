# Velisqa VPS Backend Rebuild — Claude Code Markdown Kit

**Prepared from:** uploaded `Velisqa-main.zip` (Velisqa e-commerce, not a confirmed Farriska AI repo). Current `backend/server.js` is an Express health-check stub; **this pack is an execution guide, not a completed migrated backend**.

## START

1. Extract your project into a local repo folder and copy the **contents of this kit** into that repo root (`CLAUDE.md`, all numbered `.md` files, the `audit/` and `templates/` folders).
2. Open that repo folder in Claude Code and paste the full text of **`CLAUDE_CODE_MASTER_PROMPT.md`** (or tell Claude to read and execute that file).
3. Claude must inspect and modify real source, create a separately deployable `backend/` and a proper frontend/backend split, replace production Supabase calls with HTTP fetch API, test all admin/customer actions and produce a migration/deployment report.
4. Provide access credentials *securely via local secrets* only when required; live data import and Hostinger deployment require authorized access.

## Production caveats

“Mock DB” is treated as possibly meaning *MongoDB*: a real production store must persist payment/order history. Mock repositories belong in tests only. No signed-off production cutover or live data migration is claimed from source ZIP alone.
